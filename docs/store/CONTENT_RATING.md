# Возрастной рейтинг

## Google Play (анкета IARC)

Категория: **Game**. Ответы:

| Вопрос | Ответ | Почему |
|---|---|---|
| Violence | Да, мультяшное/фэнтези-насилие против нечеловеческих персонажей, без крови и расчленения | Кот пылесосом ослабляет и затягивает мультяшных призраков |
| Fear / horror | Да, мягкие пугающие элементы | Призраки, тёмные дома, но всё в мультяшном стиле |
| Sexuality, nudity, language, drugs, alcohol, tobacco | Нет | |
| Discrimination | Нет | |
| Gambling (реальные деньги) | Нет | |
| Simulated gambling | Нет | Колесо удачи бесплатно (1 вращение в день + за рекламу), вращения не продаются |
| Interactive: users interact / share info / share location | Нет | Нет чата, профилей и обмена |
| Digital purchases | Да | Встроенные покупки |
| Random items for purchase (loot boxes) | Да | Призыв насадок за кристаллы, которые продаются; шансы показаны в игре |

Ожидаемо: PEGI 7, ESRB Everyone 10+, USK 6, с пометками «In-Game Purchases (Includes Random Items)».
